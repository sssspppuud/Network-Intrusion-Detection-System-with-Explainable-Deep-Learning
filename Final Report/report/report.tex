\section{Introduction, Motivation, and Aims}
\subsection{Motivation}
The use of smart and connected medical devices has rapidly made it's way into
the delivery of various healthcare services, leading to the rapid expansion of the
Internet of Medical Things (IoMT). This subset of the Internet of Things (IoT)
includes many medical devices such as remote heart rate monitors, temperature
trackers, and continuous glucose monitors, which can all be connected and used by
healthcare professionals to keep track of patients health and wellbeing.
Using IoMT devices allows healthcare professionals to continuously monitor patients
to make more informed decisions for diagnosis and treatment plans. For example,
data derived from IoMT devices was successfully used to predict the risk
patients have for developing heart disease \cite{baseer2024healthcare}.
However, alongside the rapid integration of IoMT technology into healthcare delivery,
the attack surface of healthcare infrastructure to also significantly expanded. By the
end of 2025, there had been 710 recorded healthcare data breaches, each of which
affecting over 500 people \cite{hipaajournal}. These breaches impacted millions of
patients, exposing sensitive medical records and other user data. Within this rapidly
evolving landscape, new vulnerabilities and cyber attacks
become major threats toward IoMT networks. Defenses such as firewalls alone,
are no longer enough to ensure the security of these networks, requiring the use of
an Intrusion Detection System (IDS) to flag malicious network activity missed by the
firewall. Traditional, signature-based IDSs often fail to detect more modern, unknown attack
signatures, leading to Machine Learning (ML) based IDSs becoming a key area of recent
research in network intrusion detection. ML based IDSs are able to recognise the
complex patterns found in network traffic to identify malicious activity, instead of
simple rule based systems. However, the lack of interpretability of these ML based
systems limits the widespread adoption, especially in healthcare setting where the
safety and privacy of both patients and staff are critical. To address this lack of
interpretability in more complex models, this project focuses on this critical gap by
developing a Deep Neural Network (DNN) IDS, and uses Explainable Artificial
Intelligence (XAI) techniques to verify the performance and accuracy of the model.
\newline
The main motivation behind this project is the requirement for transparency in safety
critical systems. Current ML-based IDS show solid performance, the reasons for
decisions they make are still very unclear, this reduces adoption in critical medical
environments because an incorrect classification could lead to disruptions in
healthcare delivery, or breaches of patients data. Existing IDS studies rely on the
use of general IoT datasets for training the models, these do not reflect the unique
traffic patterns which are found in IoMT networks, such as the use of lightweight
protocols like MQTT. This project uses the CIC2024 IoMT Dataset, this dataset has been
specifically created to benchmark and train IDS for IoMT traffic, it has been
generated using traffic collected from real IoMT devices. Although XAI techniques
such as SHAP and LIME have been used in general network security applications,
there has been little research applying these techniques specifically to IoMT
scenarios, this project aims to focus on that gap.

\subsection{Aims and Objectives}
The overarching goal of this project is to design, implement, and evaluate performance of an ML-based IDS, tailored to
IoMT network attack detection and using deep learning methods. Once this model has been implemented and it's performance
evaluated, XAI techniques (LIME or SHAP) will be applied to help explain how the model classifies different network attacks.
The results from these XAI techniques will then be discussed to verify that the model logically uses the features in the dataset
to make correct predicitons.
\newline
The four primary objectives of this project are:
\begin{itemize}
    \item Prepare the CIC2024 IoMT Dataset, making sure it is in suitable form to train the model, preprocessing steps as well as sampling techqniues will need to be applied to address the class imbalance.
    \item Design, then implement a DNN for the IDS, train it using the preprocessed training set, use retained validation set to help tune hyperparameters. Evaluate the model using evaluation metrics like F1 score, to ensure it has solid performance.
    \item Apply XAI techniques, to identify the features of network traffic which the model uses the most, as well as how different values influence the models' decisions.
    \item Critically evaluate the results from the XAI techniques, ensuring that the results align with known attack signatures and are logical.
\end{itemize}
